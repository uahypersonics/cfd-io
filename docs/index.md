# cfd-io

`cfd-io` reads, writes, and converts structured CFD data between file formats.

## Installation

Install the [PyPI package](https://pypi.org/project/cfd-io/) (see
[Installation](installation.md) for Tecplot binary support and installing from source):

```bash
pip install cfd-io
```
